# Privacy Policy — Yarn Unravel

Updated: October 10, 2026

Yarn Unravel is a fully offline puzzle game.

- **No personal data collected.** The game asks for no account, name, email, location or any identifying information.
- **No ads** and no tracking across other apps or websites.
- **In-app purchases (coin packs):** payment is handled by Google Play or the App Store; the game never receives or stores payment details. It keeps the transaction id on the device only, so a purchase is never credited twice, and never sends it anywhere.
- **No analytics:** the game sends no events or usage data over the network.
- **On-device data:** progress (current level, coins, boosters, decor, lives, language, sound and haptics settings) is stored locally and never leaves the device. Deleting the app deletes it.
- **Permissions:** the game requires no permissions beyond the OS defaults.
- **Children:** the game collects no data from anyone, children included.
